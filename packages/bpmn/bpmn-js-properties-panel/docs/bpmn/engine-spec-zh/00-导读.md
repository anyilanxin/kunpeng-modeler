# BPMN 2.0 引擎开发规范（中文精炼版）

> 本文档面向**工作流引擎开发者**，从 OMG《Business Process Model and Notation, Version 2.0》官方规范中提取与引擎执行相关的内容，剔除绘图标注、BPEL 映射、Choreography 等与执行无关的部分。

## 1. 文档目的

- **读者**：工作流引擎（BPMN 引擎）的设计者与实现者
- **目标**：在不需要通读 532 页英文原规范的前提下，给出引擎必须实现的核心语义、元模型、元素行为定义
- **不是**：BPMN 建模教程、绘图规范、流程图美学指南

## 2. 信息来源

- **唯一来源**：`docs/Business Process Model and Notation.pdf`（OMG 官方 BPMN 2.0 规范）
- **章节引用**：本文档每个章节均标注对应原规范章节号，便于回溯
- **页码引用**：用 `[原书 p.NNN]` 格式标注

## 5. 阅读路径建议

**实现最小可用引擎（MVP）**：

1. 先读 `01-合规性` 弄清必须实现什么
2. 读 `02-核心元模型` 建立类型系统
3. 读 `04-活动与任务` 实现 Task 执行
4. 读 `08-网关` 实现分支
5. 读 `07-事件机制` 实现 Start/End 事件
6. 读 `11-执行语义` 实现 Token 流转

**进阶能力**：

- 数据相关 → `06-数据与变量`
- 异常处理 → `07-事件机制` 后半段（Boundary Event）
- 事务与回滚 → `09-补偿机制`
- 多实例/批处理 → `05-循环与多实例`
- 跨流程通信 → `10-协作与会话`

## 7. 规范性条款标识

原规范区分两种条款：

- **Normative（规范性）**：引擎必须遵守的规则。本文档用 ✅ 标记。
- **Non-Normative / Informative（资料性）**：解释性说明，非强制。本文档用 ℹ️ 标记。

## 8. 已知限制

1. 本文档**不包含**完整的 XML Schema 细节（XSD 内容请直接查原规范附录）
